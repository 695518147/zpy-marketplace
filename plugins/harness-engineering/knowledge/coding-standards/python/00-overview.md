# Python 编码规范总览

本文档定义了 Python 开发的标准规范，旨在提高代码质量和一致性。

## 核心原则

1. **清晰可读** - 代码应像自然语言一样易于阅读
2. **简洁明了** - 避免过度复杂的实现
3. **类型提示** - 使用类型注解提高代码可读性
4. **异常处理** - 正确处理异常，保持程序健壮
5. **日志规范** - 合理记录日志，便于问题排查
6. **安全优先** - 防止常见安全漏洞

## 技术栈要求

- Python: 3.11+
- FastAPI / Django / Flask
- MyPy / Pyright 类型检查

## 代码风格

遵循 PEP 8 规范，使用 Black 格式化代码。
