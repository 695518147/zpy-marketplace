# TypeScript 编码规范总览

本文档定义了 TypeScript/React 开发的标准规范，旨在提高代码质量和一致性。

## 核心原则

1. **类型安全** - 充分利用 TypeScript 类型系统
2. **组件化** - 清晰分离 UI 组件和业务逻辑
3. **Hooks 规范** - 合理使用 React Hooks
4. **安全优先** - 防止常见安全漏洞
5. **测试覆盖** - 确保关键逻辑测试覆盖

## 技术栈要求

- TypeScript: 5.x
- React: 18.x
- Next.js: 14.x (可选)
- ESLint + Prettier

## 代码风格

遵循 ESLint + Prettier 配置，使用 2 空格缩进。
